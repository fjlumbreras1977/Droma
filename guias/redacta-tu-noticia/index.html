GUÍA / REDACCIÓN DIGITAL

Tu primera noticia.
De la redacción a tu web.

Un recorrido breve para preparar la estructura, trabajar el texto y llevar el resultado a tu publicación con el editor de noticias de Dröma.

5 min · Lectura y prácticaVIVA Editor PRO / Dröma
Abrir editor de noticias

En esta guía

01 · Empieza por el enfoque y la estructura.02 · Redacta y da forma al cuerpo.03 · Contrasta la información y revisa la presentación.04 · Conserva un proyecto para seguir trabajando.05 · Prepara la salida que necesita tu medio.

Empieza por el enfoque y la estructura.

Abre el editor de noticias y elige el tipo de pieza que necesitas: noticia, entrevista, crónica, reportaje o teletipo. Las plantillas sirven como punto de partida; sustituye sus textos de ejemplo por tu información.

Escribe el titular, el subtítulo si lo necesitas y la entradilla. Añade categoría, autor y fecha para mantener identificada la pieza.

Redacta y da forma al cuerpo.

Trabaja el desarrollo en el cuerpo de la noticia. Utiliza párrafos, ladillos, listas y citas cuando ayuden a la lectura. Puedes añadir enlaces, tablas e imágenes mediante una URL pública.

El banco de citas permite guardar declaraciones para incorporarlas después. Revisa su literalidad y atribución. Si insertas una imagen remota, el navegador la cargará desde su servidor.

Contrasta la información y revisa la presentación.

Consulta los recuentos de palabras, caracteres y tiempo de lectura. Los avisos sobre titular, entradilla, autor y metadescripción ayudan a revisar la pieza; son orientativos y no verifican hechos ni fuentes.

Completa el título SEO, la descripción y la URL amigable. Comprueba nombres, cifras, fechas, enlaces y contexto con tus fuentes antes de publicar.

Conserva un proyecto para seguir trabajando.

El borrador se guarda en este navegador. Utiliza Guardar proyecto para descargar un JSON editable y conservar una copia fuera del almacenamiento local.

Puedes guardar versiones manuales y consultar un historial de hasta quince versiones. Para continuar en otro equipo, abre allí el proyecto JSON. Los borradores no se sincronizan automáticamente.

Prepara la salida que necesita tu medio.

En Exportar, elige HTML para WordPress para obtener un fragmento o utiliza Copiar HTML. Pega ese contenido en el bloque o modo HTML de tu publicación y revisa cómo lo presenta el tema de tu web.

También puedes guardar una página HTML completa, texto plano, Markdown o un .doc compatible con Word. La impresión y el PDF utilizan el diálogo del navegador. El editor no publica directamente en WordPress.

El proyecto JSON conserva la sesión editable. El HTML y los demás formatos de salida sirven para compartir o publicar el contenido. Guarda las dos copias cuando las necesites.

Ya tienes el recorrido.
La historia la pones tú.
