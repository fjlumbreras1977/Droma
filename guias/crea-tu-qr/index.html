GUÍA / CREA Y COMPARTE TU QR

Tu primer QR.
Una nueva conexión.

Del contenido al diseño, la descarga y la comprobación final con QRave.

5 min · Lectura y prácticaQRave / Dröma
Abrir QRave

En esta guía

01 · Empieza por el destino y el contenido.02 · Adapta el diseño a tu pieza.03 · Exporta y comprueba el QR.04 · Conserva una copia editable.05 · Crea varios códigos desde un CSV.

Empieza por el destino y el contenido.

Abre QRave y elige entre URL, texto, WiFi, contacto, email, teléfono, SMS, WhatsApp, ubicación o evento. Completa sus campos y comprueba los datos. Para una noticia, un vídeo o una encuesta, utiliza su enlace público. El QR no aloja ese contenido: guarda la dirección de acceso.

Adapta el diseño a tu pieza.

Elige los colores del código y del fondo y una forma de módulos. Mantén un buen contraste y suficiente margen alrededor. Puedes añadir texto inferior y un logo central. Con logo, selecciona la corrección de errores máxima y comprueba la lectura; esa opción no elimina la necesidad de probarlo.

Exporta y comprueba el QR.

Descarga PNG con la resolución que necesites o SVG para una composición vectorial. Escanea el archivo final con un móvil. Si lo vas a imprimir, prueba una muestra al tamaño real: las dimensiones, el soporte, el color y la cantidad de datos influyen en la lectura.

Conserva una copia editable.

Utiliza Guardar proyecto para descargar el JSON y Abrir proyecto para recuperarlo. El historial guarda hasta 50 diseños en este navegador. Conserva una copia descargada para cambiar de equipo o evitar perderla al borrar los datos del navegador.

Crea varios códigos desde un CSV.

Prepara una columna con un contenido por línea, sin cabecera ni otras columnas. Selecciona el CSV y pulsa Crear lote de SVG. Se admiten hasta 200 códigos por lote. Se descargan archivos individuales, no un ZIP, y el navegador puede solicitar permiso para varias descargas. El lote aplica los ajustes de diseño pero omite el logo central; revisa los archivos generados.

El archivo PNG o SVG es el código listo para utilizar. El JSON conserva el proyecto editable. Guarda ambos cuando quieras publicar ahora y seguir trabajando después.
